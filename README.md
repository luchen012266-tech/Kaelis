# AO3 专属定制阅读器 (Android WebView + GitHub Actions 自动打包)

这是为你专属定制的 **AO3 安卓阅读客户端源码工程**，完全去除 AO3 原本刺眼的红色顶栏，深度还原你喜欢的柔和卡片与阅读设置面板。

## ✨ 核心定制功能
1. **去除经典红 & 全局自定义主题色**：支持预设柔和配色（雾紫、丁香、烟粉、暮山紫、云灰、羊皮纸、夜间黑）以及 **色相 / 浓淡 / 明暗** 三维滑块自由调色。
2. **自定义手机壁纸 & 背景透明度调节**：点击首页或阅读设置里的「选择手机相册背景图」，即可上传任意美图作为全局底图，并通过滑块调节 **背景与卡片透明度（20%–100%）**。
3. **1:1 还原阅读设置弹窗**：支持正文字号 `A- / A+` 滑块调节、正文字体切换（系统默认、飞花宋体、霞鹜文楷、纯净黑体）以及实时名句预览框。
4. **全界面中文化**：自动将 AO3 导航栏、搜索筛选项、作品统计标签（字数、章节、点赞 Kudos、收藏、点击）及按钮汉化为清爽中文。
5. **简洁卡片式搜索结果（点击展开/收起）**：搜索结果和作品列表自动转为圆角毛玻璃卡片，冗长的 Tag 与简介默认只显示前两行，**点击一下即可展开全部内容**。
6. **两种正文阅读方式（上下滑动 & 左右无动画翻页）**：
   - **滑动模式**：顺滑上下滚动阅读。
   - **翻页模式（零动画）**：完全禁用翻页过渡动画（`transition: none`），点击屏幕左右两侧或按 **手机音量上下键** 即可瞬时翻页，干脆利落不晃眼。

## 🚀 如何在 GitHub 上自动跑出 APK（只需 3 步）

1. **新建 GitHub 仓库**：
   登录你的 [GitHub](https://github.com/new)，新建一个仓库（比如命名为 `ao3-custom-reader`，选择 `Public` 或 `Private` 均可）。
2. **上传本项目文件**：
   把解压后的所有文件夹和文件（包括 `.github`、`app`、`build.gradle`、`settings.gradle`、`gradle.properties`）上传并提交（Commit）到仓库根目录。
   *(注意：网页上传时请确保隐藏文件夹 `.github/workflows/build-apk.yml` 一并上传，或者在仓库点击 `Actions -> set up a workflow yourself`，将 `.github/workflows/build-apk.yml` 的内容粘贴进去保存)*。
3. **下载编译好的 APK**：
   提交后点击仓库顶部的 **Actions** 标签页，等待约 1~2 分钟构建变成绿色勾 ✅，点进最新的构建记录，在底部的 **Artifacts** 区域点击 **`AO3-Custom-Reader-APK`** 即可下载生成的 APK 到手机安装！
